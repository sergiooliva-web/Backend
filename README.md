# Web Application Project

This is a simple web application with a focus on the backend, built using Python and FastAPI. It interacts with a MySQL database through SQLAlchemy and uses Pydantic for data validation. The frontend is minimal, displaying data in HTML tables.

## Features

- **Backend**: Built with FastAPI, providing high performance and automatic API documentation.
- **Database**: MySQL database with SQLAlchemy ORM for managing tables (`Customers`, `Products`, `Orders`).
- **Migrations**: Alembic is used for database migrations.
- **Frontend**: Minimal HTML + JavaScript interface to display data dynamically.

## Technologies

- **Backend**: Python, FastAPI, SQLAlchemy, Pydantic, Alembic
- **Database**: MySQL (SQLite for testing)
- **Frontend**: HTML, JavaScript
